# BlueCatch Seafood Market Website

A responsive multi-page seafood and fresh fish market template.

## Pages
- `index.html` — Home 1
- `home2.html` — Home 2 Premium
- `about.html`
- `products.html`
- `recipes.html`
- `contact.html`
- `booking.html` — Order enquiry form
- `privacy-policy.html`
- `terms-conditions.html`
- `404.html`
- `maintenance.html`

## Branding
- Logo name: **BlueCatch**
- Primary: `#082B45` — Deep Ocean Navy
- Secondary: `#16A6A0` — Fresh Teal
- Typography: Manrope + DM Serif Display
- Lucide Icons for interface/content icons
- Font Awesome only for footer social icons

## Header behavior
- Home dropdown contains only Home 1 and Home 2.
- Navigation uses compact, evenly centered spacing.
- Active page is highlighted in fresh teal with underline.
- Dark mode shows only a moon icon in light mode and a sun icon in dark mode.
- RTL control shows only RTL/LTR text.
- Both controls use primary borders/icons and teal hover states.
- Order Enquiry opens `booking.html`.

## Responsive breakpoints
- 360px
- 768px
- 1024px

## Card design
Card imagery is intentionally compact so relevant descriptive content remains the visual focus. Cards use borders, hover elevation, teal accents and reveal animations.

## Booking form
`booking.html` contains fields for name, phone, email, date, seafood choice, quantity/guests, preferred cut, order type, delivery/collection details, and preparation notes. The centered BlueCatch logo links back to Home 1, with dark mode and RTL controls at the top-right.

Additional page: `sourcing.html` with matching `sourcing.css` for the BlueCatch sourcing approach.
